Getting started

Welcome to the Acme Robotics knowledge base. Use the assistant (bottom right) to ask questions about the indexed technical documents — for example the Raspberry Pi Pico datasheet or the telecom research paper currently embedded in the store.

Try asking the widget

  • “What is the current consumption in dormant mode?”
  • “What does the BOOTSEL button do?”
  • “Summarize the spectrum allocation.”
  • “Tell me about medieval French poetry.” (should refuse — not in the docs)

How this widget was embedded

The entire integration is a single script tag:

<script src="http://localhost:8000/widget/widget.js"
        data-api="http://localhost:8000/api"></script>

Replace localhost:8000 with wherever the API is hosted.
